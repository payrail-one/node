# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Include the
affected component, reproduction steps, impact and any suggested mitigation.
Do not open a public issue for an undisclosed vulnerability.

Do not test denial-of-service techniques, destructive payloads or attempts to
access other users' data against the hosted Payrail development network. Use a
local node for proof-of-concept work.

## Scope

The repository is a development-network reference. Test assets have no monetary
value and single-node development finality is not a production security claim.
Reports about credential exposure, signature verification, replay protection,
monetary invariants, persistence integrity and parser or transport boundaries
are especially useful.
